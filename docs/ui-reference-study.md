# Photo editor workflow rationale

## Dither4All changes

1. Use a neutral dark canvas and subdued native-style controls to keep attention on image colors.
2. Put the image on the left and all adjustments in one scrollable right inspector. Remove both the Dither/Adjust/Palette tabs and small-screen workspace switching.
3. Present Style, Preset, Scale, Color, Adjustments, Effects, and Output in a continuous order with clear section headers.
4. Keep Open image and Export image pinned at the top of the inspector.
5. Add effects with an inline selector and Add button. Keep intensity, toggles, removal, and ordering in the same inspector.
6. Edit palettes as compact swatches with import, extraction, and save nearby. Save named presets inline rather than opening an editing dialog.
7. On phones, keep the image above a separately scrolling inspector so changing a control never replaces the preview.
8. Retain utility dialogs for batch processing, help, and privacy information; core editing requires none of them.

The visual treatment, branding, components, and implementation are original.
